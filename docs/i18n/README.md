# Translations

Community translations of the core documents. English is authoritative; if a
translation and the English source disagree, the English source wins. These
cover the documents an owner needs to install and recover the camera; the
developer docs (architecture, API, building) stay English-only.

| Language | README | Install | Recovery |
|---|---|---|---|
| Português do Brasil | [README](pt-BR/README.md) | [Instalação](pt-BR/INSTALL.md) | [Recuperação](pt-BR/RECOVERY.md) |
| 简体中文 | [说明](zh-CN/README.md) | [安装](zh-CN/INSTALL.md) | [恢复](zh-CN/RECOVERY.md) |
| Русский | [README](ru/README.md) | [Установка](ru/INSTALL.md) | [Восстановление](ru/RECOVERY.md) |
| Deutsch | [README](de/README.md) | [Installation](de/INSTALL.md) | [Wiederherstellung](de/RECOVERY.md) |
| Español | [README](es/README.md) | [Instalación](es/INSTALL.md) | [Recuperación](es/RECOVERY.md) |
| Français | [README](fr/README.md) | [Installation](fr/INSTALL.md) | [Récupération](fr/RECOVERY.md) |

These languages match the ones the camera's own web console offers. The console
translations live in [`media/ui/i18n/`](../../media/ui/i18n/).

To correct or add a translation, edit the file under its language folder and
open a pull request. Keep the Markdown structure identical to the English
source and never translate code, commands, paths or link targets.
