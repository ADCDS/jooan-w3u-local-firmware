# JOOAN W3-U 本地固件

<p align="center">
  <img src="../../../docs/images/w3u-camera.jpg" width="320"
       alt="手中拿着的 JOOAN W3-U 摄像机：两个镜头上下叠放在同一个白色云台外壳中，配有两根 Wi-Fi 天线和一根以太网尾线">
  <br>
  <sub>本项目针对的摄像机：JOOAN W3-U（<code>JA-A12</code>），双镜头。</sub>
</p>

这是一款本地优先的固件，专为一款确切型号的摄像机而设计：JOOAN W3-U（`JA-A12`）。它切断摄像机与 JOOAN 云服务及 P2P 服务的连接，并以需要身份验证的本地服务取而代之：Web 控制台、SSH、RTSP 视频，以及供 Frigate 等 NVR 使用的 ONVIF 云台控制和预置位。

它并不是一套完整的开源固件。厂商的引导加载程序、Linux 3.10 内核、内核模块、传感器调校参数和无线芯片固件都会保留，厂商的摄像机程序 `jooanipc` 也会保留下来作为后备。在此基础上再安装两层：

- **平台层**（本仓库根目录）安装到可写的 `/opt` 分区。它提供 Web 控制台和 API、SSH、Wi-Fi、时钟和签名更新，并使摄像机无法访问互联网；
- **媒体守护进程** [jooanipc-open](../../../media/) 安装到应用分区。它负责提供视频、ONVIF 和云台控制，因此在正常（原生）启动时，厂商程序根本不会启动。

[架构](../../../docs/ARCHITECTURE.md)一文介绍了各种启动模式和信任边界。

## 状态

- **工程预发布版；目前尚无任何受支持的版本。** 所有版本都在一台实体摄像机上进行测试。只有当签名安装与卸载、迁移、Wi-Fi、网络时间、SSH、路由、断电和冷恢复检查全部在该摄像机上通过后，一个版本才会成为受支持版本（[硬件晋级门禁](../../../tests/TEST_PLAN.md#hardware-promotion-gates)）。
- **已发布：v0.2.39**（2026-11-07）：包括平台软件包，以及首次发布的媒体层二进制文件和脚本。由于应用分区中含有厂商文件，每位所有者仍需基于自己摄像机的应用分区来构建该摄像机的镜像，因此本项目不发布任何镜像。
- **整条流程现已在一台真实摄像机上端到端地运行过一次。** 一台测试摄像机先被恢复为原厂状态，然后在不使用厂商 App 的情况下完成 Wi-Fi 配网，通过 OTA 更新到平台层，再刷入基于其自身分区构建的媒体镜像；它通过 RTSP 提供了视频，并在开源软件栈上经受住了冷重启（参见[往返测试报告](../../../docs/reports/hardware-roundtrip-20261108.md)和[媒体层](./INSTALL.md#the-media-layer)）。由于这条流程只运行过一次，请仍将其视为预发布版本：务必让安装程序完成完整备份，并在刷写期间保持摄像机通电。
- **v0.2.21**（2026-10-16，仅含平台层）仍保持发布状态。它是最后一个在原厂摄像机上安装过的版本。使用该版本时，视频仍由厂商程序提供，该程序在受限环境中运行。

## 确切的硬件范围

请仅在完全符合以下所有条件的设备上使用本项目：

- OEM 固件报告的产品/型号：`JA-A12` / 软件包标识 `A12`；
- PCB：`JA-6621 V1.0`；
- SoC：Ingenic T23N；
- 图像传感器：双传感器 `cv2005` 和 `cv2005s1`；
- 无线芯片：USB 接口的 SeekWave SKW6316（已验证设备上为 `SV6160LITE`）；
- 闪存：8 MiB SPI NOR（已验证设备：Puya P25Q64HA）。

已验证设备的零售包装盒上标注：品牌 `JOOAN`，型号 `W3-U`，FCC ID `2BBQ4-W3U`，5 V / 1.5 A。这些信息只能确定产品名称，而仅凭产品名称是不够的：是否兼容由上面的清单决定。名为“Jooan W3-U”的 Thingino 镜像针对的是采用 SC2336P/ATBM6132U 的另一个硬件版本，两者不可互换。产品名称和外壳形状都不能作为兼容性依据。安装任何内容之前，请先阅读[兼容性](../../../docs/COMPATIBILITY.md)。

## 可用与缺失的功能

使用 0.2.39 及其媒体层时：

- **可用：** 两个镜头的 RTSP 视频（1920×1080 和 1024×576，均为 15 fps，H.264）；供 Frigate 使用的 ONVIF 云台控制和 16 个可命名的预置位；每次启动时自动归位；画面翻转、手动夜视/IR-cut 切换和白光灯；位于 `https://<camera>/` 的统一管理界面，适用于手机和电脑（`http://<camera>/` 会重定向到该地址）；SSH；Wi-Fi 设置，支持网络列表、静态地址，以及暂存、提交和回滚；重启、每日重启和恢复默认设置；隐私模式；预置位巡航；精确的 ONVIF 移动；可选的网络时间同步（从本地服务器获取）；mDNS；签名更新。
- **默认开启（除非设置 `audio=0`）：** 音频（麦克风声音随 RTSP 传输；可从 Frigate、管理界面或 API 通过扬声器对讲）。
- **缺失：** 移动侦测和人形检测；数字变焦；画面 Logo 叠加；机内录像（在经过验证的配置中为关闭状态：请使用 NVR 录像）和 SD 卡管理；任何云端或手机 App 访问。

[OEM 对比](../../../docs/OEM-COMPARISON.md)逐项比较了本固件与厂商固件。

## 安装

请按照[安装指南](./INSTALL.md)操作。首次安装通过 Wi-Fi、借助厂商固件自带的更新程序完成，之后的更新则通过 Web 控制台进行。整个过程无需 SD 卡、线缆或闪存编程器，也无需拆开摄像机。只有在恢复已无法启动的摄像机时才需要用到闪存编程器（参见[恢复](./RECOVERY.md)）。

如果想在不使用终端的情况下按引导完成安装，可以使用[安装程序](../../../installer/)：它在一个窗口中封装了整套流程——配网、平台更新、备份、构建和刷写。它默认以试运行（dry run）模式启动，只规划全部步骤而不做任何改动；运行时会显示实时日志，并且只在唯一不可逆的步骤之前询问一次确认。

## 安全概要

- 摄像机必须接入一个禁止其访问互联网的网络。每次启动时，在本固件接管之前，厂商的 Web 服务器会先运行几秒钟。本固件会删除摄像机的默认路由，但没有包过滤功能，因此路由器层面的隔离才是真正的安全边界。
- Web 控制台和 API 使用 80 端口上的明文 HTTP。请求必须通过私有或回环 IP 地址，或者通过摄像机自身的名称来访问摄像机（名称默认为 `jooan-w3u`，可以单独使用，也可以加上 `.local`、`.lan`、`.home.arpa` 或 `.internal` 后缀）。其他任何请求都会收到 `403 host_rejected`。
- 登录账号为 `admin`，初始密码为 `admin`。在“系统”页面修改之前，该密码一直有效；SSH 也使用同一密码。媒体守护进程有自己的凭据、自己的 TLS 证书和登录失败限流机制。
- `telnetd` 和厂商的 Web 服务器每秒都会被终止一次。当厂商程序运行时（仅限后备模式），一个防护组件会拦截其云端流量，并将其监听端口限制在回环地址上。

详情请参阅[网络安全](../../../docs/NETWORK-SECURITY.md)和[安全策略](../../../SECURITY.md)，后者还说明了如何报告漏洞。

媒体守护进程加载的 `libimp.so` 由 OpenIMP 派生项目（fork）的 [`jooan/oem-t23-abi`](https://github.com/ADCDS/openimp/tree/jooan/oem-t23-abi) 分支构建而成，该派生项目是一个独立的仓库。

本仓库及其发布版本不包含任何出厂机密、Wi-Fi 凭据、设备密钥、闪存转储、OEM 固件或其他厂商二进制文件。如果需要用到保留下来的 OEM 组件，这些组件均取自所有者自己的摄像机。媒体层发布包中含有一个基于该摄像机重新构建的 appfs 镜像，因此这类发布包始终保持私有。
